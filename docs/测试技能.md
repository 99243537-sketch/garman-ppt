# 兼容性测试技能（garman-ppt-probe）

正式技能发布前用来检查某个智能体能不能跑生成脚本。它不做 PPT，只生成一份 5 页测试稿《矿物色PPT-兼容性测试稿.pptx》，用来在 PowerPoint 和 WPS 里检查动画、毛玻璃和字体。

## 用法

从 Release 下载 `garman-ppt-probe-x.y.z.zip`（预发布版），发给智能体（WorkBuddy、OpenClaw 等），说：

「请按 SKILL.md 运行兼容性测试」

拿到测试稿后，按 `skill-probe/garman-ppt-probe/测试清单.md` 逐项放映检查。
