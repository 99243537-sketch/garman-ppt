# 更新 v6：网页版先限 5000 字（2026-10-20）

赵老师决定：长文档（上万字）MiniMax 太慢，网页版先只做 5000 字以内的文档，超过的提示拆开或改用技能。长文档分段处理以后再做。

## 步骤

1. 换 3 个文件：
```
cp ppt/app.js ppt/index.html /www/www.zhaodun.work/ppt/
sudo cp ppt-planner/app.py /opt/ppt-planner/
```
2. 打开 `/opt/ppt-planner/.env`，把 `MAX_DOC_CHARS=30000` 改成 `MAX_DOC_CHARS=5000`（没有这一行就不用加，新默认值就是 5000）。
3. 重启：
```
sudo systemctl restart ppt-planner
```

## 改了什么
- 网页先在浏览器里数字数，超过 5000 字直接提示「网页版目前最多支持 5000 字，请拆成几份；长文档也可以用技能在 WorkBuddy、ChatGPT 等工具里制作」，不调用大模型、不扣次数。
- 上传框下的说明改为「最多 5000 字」。
- 服务器同样把关 5000 字。
