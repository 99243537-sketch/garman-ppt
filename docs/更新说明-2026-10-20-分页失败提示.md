# 更新：分页失败时的中文提示与自动重试（2026-10-20）

只替换 4 个文件，不动 doc2ppt.browser.js、限流配置和 .env。

```
cp ppt/app.js ppt/index.html /www/www.zhaodun.work/ppt/
sudo cp ppt-planner/app.py ppt-planner/prompt.md /opt/ppt-planner/
sudo systemctl restart ppt-planner
curl -s http://127.0.0.1:8790/api/health
```

## 改了什么

- 后端：模型输出不是合法 JSON 时，返回中文提示和错误码（plan_parse_failed / plan_truncated / upstream_error），不再透出英文异常；能识别「输出被截断」（finish_reason=length）。
- 后端：修正次数改为成功后才 +1，解析失败不占用修正机会；失败的请求照旧不计入每日 5 次。
- 后端：MAX_OUTPUT_TOKENS 默认值 16000 → 24000；提示词要求模型输出紧凑 JSON，减少截断。若 MiniMax 报「max_tokens 超限」，在 .env 里把 MAX_OUTPUT_TOKENS 调回 16000。
- 前端：可重试的错误自动再试一次；仍失败则显示中文提示和「再试一次」按钮；英文错误一律不显示给学员。
