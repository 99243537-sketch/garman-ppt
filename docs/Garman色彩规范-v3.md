# Garman 色彩规范 v3（自然色）

v3 把赵盾矿物色彩系统 v2.3 里「做在里面、没写下来」的结构量出来，写成规则。按这套规则，任何自然物（矿物、贝壳、鸟类、花卉、果实、树叶、昆虫）都能推出一套配色，而且看得出是同一个系列。

## 一致性从哪来

色相只负责换衣服，一致性来自明度和彩度。把 13 套样张转成灰度图，几乎分不出来。

1. **明度骨架固定**（OKLCH 明度，感知均匀）：浅底 97、柔底 94、主色 78、深字 48、深底 28；正文 31、灰字 50、分隔线 86。
2. **彩度克制**：主色 0.09 左右（雅致档）；中性色只带 0.01–0.03 的主色调，不用纯灰。
3. **色相关系**：一个主色 + 一个点睛色，点睛色尽量取主色的对比色（色环对面），整页只用一处（结论句、封面竖线）。
4. **深底取环境色**：深底不必与主色同族，取这个自然物所在的环境（栾树的林荫墨绿、乌桕的枝干、鹦鹉螺的深海）。v2.3 的青金石比天河石偏冷约 45°，同理。
5. **面积比例**：浅底约七成，主色与深色两成多，点睛色一页一处。

## 两档

- **雅致**（默认）：主色彩度约 0.09。
- **鲜明**：只放开主色（明度 76–86、彩度 0.11–0.15），其余不变。用于辨识度靠高彩度的自然物，如银杏、翠鸟、黄金宝螺。

## 对比度底线（脚本自动检查，不达标不出）

| 组合 | 最低 |
|---|---|
| 正文、标题 / 浅底 | 7:1 |
| 眉题、结论、页脚 / 浅底 | 4.5:1 |
| 封面标题 / 主色 | 4.5:1 |
| 章节标题 / 深底 | 7:1 |

点睛色太亮（如黄色）时自动压暗到够看清，所以黄色点睛会变成姜黄。

## 怎么加一套新配色

1. 拍或找一张颜色清楚、光线自然的照片。
2. 量出主色、点睛色、深底（环境色）的色相和彩度。
3. 写进 `tools/palette/derive.py` 的 `THEMES`，运行生成 `tools/doc2ppt/src/themes.js`，脚本会检查对比度。
4. 和现有各套比色差（主色 60%、点睛 25%、深底 15%，OKLab ΔE），太近的不收。
5. 重新打包 `skill/garman-ppt/scripts/doc2ppt.cjs`，更新 SKILL.md 的配色表和 `references/配色一览.jpg`。

## 0.3.0 收录的 13 套

天河石（默认）、鹦鹉螺、鲍鱼壳、翠鸟、红嘴蓝鹊、鸢尾、梅花、栾树、槭枫、乌桕、黄金宝螺、银杏、吉丁虫。

试做后舍弃（与保留的某套太近）：荷花→梅花，蝾螺→槭枫，红玉髓、伯劳、鸳鸯→乌桕，大黄蜂→银杏，领雀嘴鹎→吉丁虫，长鼻螺→鹦鹉螺，红胁蓝尾鸲（夹在天河石与翠鸟之间），笔螺→黄金宝螺。

## 以后

- **多主色**：乌桕（黄、橙、珊瑚）、鸳鸯、鲍鱼壳的特征是「一物多色」，可让卡片在同一明度的 2–3 个相邻色相间轮换。
- **红色系深色封面**：红色主色固定在明度 78 只能是粉色；要表现乌桕深红、红梅，需要封面改成深红底白字。
- 毛玻璃（实验效果）13 套都能用：背景由该套的主色、深字、点睛、柔底色块模糊交融，再朝深底色压暗（`tools/doc2ppt/make_glass.py`），玻璃内白字约 7.4:1、页脚约 5.25:1。暖黄系压暗后偏橄榄、偏褐。
