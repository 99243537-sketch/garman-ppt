# 小更新：修正更快、重复提交自动接上（2026-10-20 第 2 次）

如果已经装过 ppt-web-update3.zip，再装这个也没关系，同样 3 个文件覆盖即可。

只换 3 个文件，其余不动。

```
cp ppt/app.js ppt/index.html /www/www.zhaodun.work/ppt/
sudo cp ppt-planner/app.py /opt/ppt-planner/
sudo systemctl restart ppt-planner
```

然后在 Cloudflare 对 `https://www.zhaodun.work/ppt/` 再 Purge 一次。

改了什么：
- 大模型修正时只回有问题的那几页，不再重写整份方案，输出短很多，修正通常不到 1 分钟。
- 备注漏段、重复，页面放不下的长摘句，由网页自己处理（补整段原文 / 在逗号处截短，仍是原文），不再去找大模型。
- 修正次数改为成功后才算：服务失败后点「再试一次」，会真的再修正，不会直接放弃。
- 同一个人对同一份文档重复提交（页面没收到回复、刷新等），自动接上后台正在做的那一份，不再提示「已经有一份正在制作」；如果是另一份文档，提示里会写明文档名和已等待的秒数。
