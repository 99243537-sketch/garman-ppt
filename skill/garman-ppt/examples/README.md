# 示例

每个示例都有 `paras.txt`（parse 的输出）和对应的 `plan.json`（分页方案）。

- `大纲示例/`：一份很短的 Markdown 工作总结。演示讲述规则（`takeaway` 放封面副标题和回顾页、结论句标题、标签放 `kicker`、每页 `bridge` 连接句）、卡片加箭头、正文页，以及错别字修改清单（「在接再厉」→「再接再厉」，`accepted: true` 表示用户已确认）。`check` 和 `lint-plan` 都能通过。
- `公文示例/`的标题已经是结论句，但写于 0.3.3 之前，没有 `takeaway` 和 `bridge`，`lint-plan` 会报这两项。
- `公文示例/`：《关于进一步加强金融支持妇女就业发展的实施意见》（新闻稿 + 正文，约 4200 字）。演示封面、导语卡片页、目录、5 个章节，共 14 页。
