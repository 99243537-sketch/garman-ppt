# 示例

每个示例都有 `paras.txt`（parse 的输出）和对应的 `plan.json`（分页方案）。

- `大纲示例/`：一份很短的 Markdown 工作总结。演示封面副标题放主线、结论句做标题、卡片只放标题（整页统一）、卡片加箭头、正文页，以及错别字修改清单（「在接再厉」→「再接再厉」，`accepted: true` 表示用户已确认）。
- `公文示例/`：《关于进一步加强金融支持妇女就业发展的实施意见》（新闻稿 + 正文，约 4200 字）。演示封面副标题放主线、导语卡片页、5 个章节（章节超过 4 个，所以不做目录），卡片整页统一带正文、不用 kicker 和结论句，共 13 页。
