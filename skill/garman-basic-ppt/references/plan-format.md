# 分页方案 plan.json 格式

## 摘句的写法

凡是要显示在页面上的文字，都写成 `["段落编号", "原文摘句"]`：

```json
["P003", "对信用良好的女性创业者适当降低或取消反担保要求"]
```

摘句必须是该段落里**连续的一截原文**，逐字照抄。脚本会核对，对不上就报错。

备注只写段落编号，脚本会把完整原文放进去：`"notes": ["P003", "P004"]`。

## 整体结构

```json
{
  "theme": "天河石",
  "style": "normal",
  "footer": ["P001", "页脚文字（通常是文档标题）"],
  "corrections": [
    { "para": "P006", "from": "在接再厉", "to": "再接再厉", "reason": "成语错字", "accepted": false }
  ],
  "slides": [ …每页一个对象… ]
}
```

`style`：`"normal"` 普通效果（默认），`"glass"` 毛玻璃效果。整份文件统一，不能按页单独设置。

`theme`：配色名称，只能用 SKILL.md「配色」一节表里的 13 个名称之一，默认 `"天河石"`。整份文件统一。13 套都能配普通和毛玻璃两种效果。生成时可用 `--theme` 临时换配色或一次生成多个配色版本，不必改这里（见 SKILL.md 第 5、7 步）。

`theme`、`style`、`footer` 和 `corrections` 都可以省略。

## 六种页面

| type | 用途 | 字段 |
|---|---|---|
| `cover` | 封面 | `title` 必填；`sub` 副标题放主线（听众最该记住的一件事）；`kicker`（标题上方小字，可放单位、日期）可选；`notes` |
| `toc` | 目录 | `items`：2–4 个摘句（脚本允许 6 个，本技能最多用 4 个；章节超过 4 个就不做目录）；`notes` |
| `section` | 章节过渡页 | `no`（如 "01"）、`title`、`sub` 可选；`notes`。`title` 摘句不要带原文序号（见下「序号」） |
| `cards` | 卡片页，带讲课动画 | 见下 |
| `text` | 正文页，无动画 | `title`、`points`：1–2 条摘句（脚本允许 3 条，本技能最多用 2 条；每条 ≤ 80 字，宁短勿长）；`kicker` 默认不用；`notes` |
| `end` | 结尾页（显示「谢谢」） | `notes` |

### cards 卡片页

```json
{
  "type": "cards",
  "title": ["P010", "助力妇女就业发展"],
  "arrows": false,
  "intro": ["P010"],
  "cards": [
    { "no": "一", "head": ["P011", "加大对妇女就业创业重点领域金融支持"],
      "body": ["P011", "支持低收入妇女、因生育中断就业妇女等群体就业创业"],
      "notes": ["P011"] }
  ],
  "end": ["P013"]
}
```

- `cards` 2–3 张，最多 4 张（脚本允许 5 张，本技能不用）。更多就拆成两页。
- `no`：卡片编号，1–3 个字。原文有「（一）」「1.」时照用「一」「1」。
- `head` 卡片标题从序号**后面**开始摘，编号只写在 `no` 里（见下「序号」）。
- `head` 卡片标题必填，优先摘结论、数据、具体做法；都必须是摘句。
- `body` 正文只在有数字或具体做法时才放。**同一页的卡片要么都带 `body`，要么都不带。**
- `kicker`、`conclusion` 默认不用。只有拆页后标题相同的两页，才用 `kicker` 区分。
- `arrows: true`：卡片之间是先后步骤时加箭头。
- `intro`：进页时讲的段落；`end`：最后一次点击时讲的段落；每张卡片的 `notes`：点到这张卡片时讲的段落。脚本会按【点击 1】【点击 2】……分段写进备注。
- 动画由脚本完成：卡片逐张出现，上一张变淡；最后一次点击全部恢复。

## 序号：只出现一次

章节页的 `no`、目录的 1 2 3、卡片的 `no` 都会显示成编号。原文小标题自带序号（「一、」「（一）」「1.」「第一章」「①」等）时，摘句从序号**后面**开始摘，否则页面上会出现「01　一、……」这样的双重编号。

| 原文 | ✗ 不要 | ✓ 要 |
|---|---|---|
| 一、为什么要更新到3.0版？ | `["P005", "一、为什么要更新到3.0版？"]` | `["P005", "为什么要更新到3.0版？"]` |
| （一）加大对妇女就业创业重点领域金融支持。…… | `["P011", "（一）加大对妇女就业创业重点领域金融支持"]` | `["P011", "加大对妇女就业创业重点领域金融支持"]`，`"no": "一"` |

从序号后面摘仍是原文里连续的一截，符合「只摘不写」。万一漏了：生成时脚本会自动去掉章节页标题（有 `no` 时）、目录项、卡片标题开头的序号，`check` 用「!」提示。`kicker`、`text` 页标题、封面不显示编号，原文序号可以保留。

## 分页原则

1. **跟着原文结构走。** 原文的一级标题 → `section` 页；其下并列的几条 → 一个 `cards` 页（每条一张卡片）；开头导语、结尾落款 → 放进相邻页面的备注。
2. **一页一件事，标题结论优先。** 卡片页、正文页标题用原文里最能概括这一页的**结论句、数据或具体做法**（≤ 26 字）；「背景」「主要成效」这类标签只在原文没有结论句时才用。
3. **卡片标题用原文现成的小标题。** 比如「（一）加大对……金融支持。」里句号前的那半句。原文没有小标题，就选这段里最关键的短语。
4. **卡片正文选最有信息量的一句。** 优先选数字、具体做法，少选空泛的表态。宁短勿长。
5. **超过 4 条就拆页**（最好 2–3 条一页）。两页的标题可以相同，这时用 `kicker` 区分。
6. **只有一两句话的段落**用 `text` 页，不要硬做成卡片。
7. **常见的页面顺序**：封面（副标题是主线）→（导语卡片页）→ 目录（≤ 4 项）→ 各章节（章节页 + 内容页）→ 结尾页。
8. **不知道该不该放，就放进备注、不上页面。** 页面宁少勿多。

## 校验会检查什么

上面的硬上限（卡片 ≤ 4 张、目录 ≤ 4 项、正文页 ≤ 2 条、body 整页统一、kicker 和结论句默认不用）`check` **不会**检查，写方案时自己遵守。`check` 检查的是：

- 摘句是否逐字来自原文；页面类型是否属于这六种；
- 章节页标题、目录项、卡片标题开头是否带了原文序号（提示并在生成时自动去掉）；
- 卡片数、目录项数、各处字数能否放得下（放不下会提示换更短的摘句）；
- 每段原文是否都在备注里、有没有重复；
- 修改清单里要改的字是否真在那一段里。
