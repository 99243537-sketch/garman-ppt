## 1. 第 2 页 · 变淡动画（现有做法）

| 检查项 | PowerPoint | WPS |
|---|---|---|
| 进页时三张卡片都不显示 | ☐ | ☐ |
| 点击 1：第一张出现 | ☐ | ☐ |
| 点击 2：箭头和第二张一起出现，第一张变淡 | ☐ | ☐ |
| 点击 3：第三张出现，第二张变淡 | ☐ | ☐ |
| 点击 4：全部恢复正常，橙红结论句出现 | ☐ | ☐ |

| 检查项 | PowerPoint | WPS |

| 动画：逐张出现、上一张变淡、第 4 次点击恢复 | ☐ | ☐ |
