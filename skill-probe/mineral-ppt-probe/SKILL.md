# 天然矿物色 PPT 讲稿制作 · 兼容性测试

这是正式技能发布前的测试版，只做两件事：

1. 检查当前环境能不能运行生成脚本（需要 Node.js 16 或以上，以及可写的输出目录）；
2. 生成一份 5 页的测试稿《矿物色PPT-兼容性测试稿.pptx》，内容是「iPhone 用户 Claude 接入 GitHub 攻略」。

## 怎么做（按顺序）

1. 找到本技能目录下的 `scripts/probe.cjs`。
2. 在终端运行（输出目录用用户的工作目录或桌面，不要写进技能目录本身）：

   ```
   node scripts/probe.cjs <输出目录>
   ```

   - 这个脚本是单文件，**不需要 npm install**，也不需要联网。
   - 不要修改脚本，不要改用其他方法重新生成 PPT。这一步测的就是脚本本身能不能在这里运行。
3. 把脚本打印的**全部输出原样**告诉用户。
4. 结果分三种：
   - 显示「环境检查通过，测试稿已生成」：把生成的 .pptx 文件交给用户，并提醒他按 `测试清单.md` 在 PowerPoint 和 WPS 里分别放映检查。
   - 显示「环境检查未通过」：如实说明是哪一项没通过（Node 版本太旧，或目录不可写）。
   - 提示找不到 `node` 命令，或者当前环境根本不能运行终端命令：如实告诉用户「此环境不能运行 Node 脚本」。**不要**用别的办法代替生成，这个结论本身就是测试结果。
5. 不需要解释测试稿的内容，也不需要评价效果；检查由用户自己放映完成。

## 文件

| 路径 | 内容 |

| `测试清单.md` | 给用户的放映检查清单 |
