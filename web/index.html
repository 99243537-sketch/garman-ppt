天然矿物色 PPT 讲稿制作

上传已经定稿的文档，生成可编辑的 PPT：页面只放原文摘句，完整原文放进讲稿备注，卡片带讲课动画。

请勿上传涉密材料。含个人信息（姓名、身份证号、手机号等）的文档请先脱敏。文件在你的浏览器里读取和生成，本站不保存；只有段落文字会发送给大模型（MiniMax）做分页。

1. 选择文档

点击选择或把文件拖到这里
支持 .docx、.md、.txt，最多 3 万字；.doc 请先另存为 .docx

2. 正在制作

  1. 读取文档、整理段落
  2. 大模型分页、挑选原文摘句（约 1–2 分钟）
  3. 逐字校验，必要时自动修正
  4. 排版生成 PPT

请确认错别字

勾选同意修改的条目；不勾的保持原样。修改会同时用于页面和讲稿备注。

3. 完成

请用 PowerPoint 或 WPS 放映检查一遍；手机预览可能替换字体、看不到动画。

配色：赵盾矿物色彩系统 v2.3 · 色彩规范 · 分页：MiniMax 大模型 · 生成工具 doc2ppt
