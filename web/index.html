GarmanPPT

上传已经定稿的文档，生成可编辑的 PPT：页面只放原文摘句，完整原文放进讲稿备注，卡片带讲课动画。

接着上次的

请勿上传涉密材料。含个人信息（姓名、身份证号、手机号等）的文档请先脱敏。文件在你的浏览器里读取和生成，本站不保存；只有段落文字会发送给大模型（MiniMax）做分页，服务器用完即丢。制作进度只暂存在你自己的浏览器里，24 小时后自动清除。

1. 选择文档

点击选择或把文件拖到这里
支持 .docx、.md、.txt，最多 5000 字（更长的请拆开，或用技能制作）；.doc 请先另存为 .docx

点图片看大图。卡片页放映时会一张张出现，讲到下一张时上一张变淡。

2. 正在制作

  1. 读取文档、整理段落
  2. 大模型分页、挑选原文摘句（约 1–2 分钟）
  3. 逐字校验，必要时自动修正
  4. 排版生成 PPT

请确认错别字

勾选同意修改的条目；不勾的保持原样。修改会同时用于页面和讲稿备注。

3. 完成

请用 PowerPoint 或 WPS 放映检查一遍；手机预览可能替换字体、看不到动画。苹果手机和 Mac 没有微软雅黑，打开时字体会被替换，在 Windows 电脑上放映就是正常的。
